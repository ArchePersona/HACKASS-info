# IP and Licensing

HACKASS is currently proprietary.

The intent for now is to keep the IP while preserving the option to open-source some or all of the work later.

## Current license state

The root `LICENSE` file controls the current license status.

At present:

- all rights are reserved;
- public repository visibility does not grant reuse rights;
- no open-source license has been granted;
- no permission is granted to copy, modify, distribute, host, deploy, train on, or create derivative works without written permission;
- HACKASS remains protected intellectual property.

## Public does not mean open source

This repository may be public so people can understand the thesis, positioning, and product direction.

That does not mean the work is free to use.

A public repository without an open-source license remains proprietary by default.

## Possible future open source path

The project may later choose to open-source selected parts of HACKASS.

Possible future paths include:

- open-sourcing documentation only;
- open-sourcing a limited SDK or adapter layer;
- open-sourcing a community edition;
- keeping core orchestration proprietary;
- releasing the whole project under a permissive or source-available license.

No future licensing path is active until it is explicitly written into the repository.

## Current position

For now, keep the IP.

The spear can be visible without handing away the weapon.
