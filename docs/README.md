## System boundary

HACKASS is the program the user communicates with.

ARCHESTRATOR is the engineering engine underneath it.

ROSIE is the local-machine bridge/runtime that translates authorized engineering actions into operations on the machine where the work lives.

These are separate responsibilities and should not be collapsed into one component in product or architecture descriptions.

## Current status

For now, HACKASS keeps the IP.

The repository may be public for visibility, review, positioning, or discussion, but it is not currently open source.

The root `LICENSE` controls use of the work.
